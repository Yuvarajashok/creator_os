# Contributing

Read [README.md](README.md), [SETUP.md](SETUP.md), and [known issues](docs/TESTING_AND_LIMITATIONS.md).

Use [GitHub Issues](https://github.com/Yuvarajashok/creator_os/issues) for reproducible reports with expected/actual results and non-sensitive examples. Do not post .env contents, tokens, database exports, or personal analytics.

Keep changes focused. Documentation must distinguish implemented behavior, mock data, proposed features, and executed test results. Run relevant checks for implementation changes and state any blockers honestly.

For ML changes, record data provenance, split strategy, baseline, and measured results. Do not claim future-growth prediction from in-sample engagement scores.

The original README declared MIT, but the repository lacks a complete license file. The owner should supply the license text and attribution; contributors should not invent them.
